# 碎碎清单：网页测试版

直接打开 `index.html`，或使用本地预览服务。

## 这一版能做什么

- 新增、编辑、分组、置顶和删除待办。
- 点击完成后，文字随三角碎片散开，再显示划线和半透明的已完成状态，并移到框内清单最末尾。未完成事项优先显示，已完成事项按完成顺序排列；再次点击可恢复到未完成区域。
- 待办框内部可上下滚动查看全部事项，标题和底部入口保持固定；完成操作保留滚动位置。
- 在完整清单中查看全部事项、恢复已完成事项。
- 撤销完成、删除和恢复示例操作。
- 选择强调色、清单密度、壁纸及碎裂幅度。
- 独立调整待办框材质（磨砂、玻璃、平面）、任意底色和透明度，选择自动/浅色/深色文字。
- 当前浏览器本地保存；导出 / 导入备份（合并或替换），与原生版互通。
- 每天重复的事项；前一天完成的事项第二天自动移入“历史”，可放回。
- 锁屏提醒：从主屏幕打开（iOS 16.4+）后在“设置”开启，离开应用时未完成事项出现在锁屏通知里；应用图标显示剩余数。通知里不能勾选。
- iPhone Safari 首次打开会提示“添加到主屏幕”。
- 尊重系统减少动态效果设置。

初始待办是示例数据。正式产品名未定。

## 在 iPhone 上体验

使用 Safari 打开 HTTPS 部署地址，确认顶部说明窗口显示离线就绪后，通过分享菜单添加到主屏幕。首次从图标启动也请保持联网，确认缓存完成。临时地址需要电脑及隧道运行，固定地址需要静态托管。

电脑和 iPhone 接入同一个局域网时，也可访问电脑的 HTTP 本地预览地址，但该地址不支持手机上的 Service Worker 离线缓存。

新增 `manifest.webmanifest`、`pwa.js`、`sw.js` 和 `icons/`。所有运行资源本地缓存；修改缓存资源后必须修改 `sw.js` 中的 `VERSION`。版本更新按钮位于顶部说明窗口，不自动刷新正在编辑的页面。

## 交付边界

这是网页原型，不是 iOS 安装包，也不会设置真实锁屏。没有执行苹果开发者注册、云端构建、付费购买或 App Store 发布。

原生 iOS 版源码在 `../ios/`（ActivityKit / WidgetKit / App Intents），仍需编译、签名和真机验证。网页碎裂和卡片内滚动不代表 Live Activity 已具备相同能力。模拟卡片每屏可见三或四条，内部可滚动全部事项。

数据不跨浏览器、不跨设备同步；换设备请导出备份再导入。

自动文字颜色根据所选底色的对比度选择；高透明度叠加自定义壁纸时，仍可能需要手动切换文字深浅或降低透明度。

## 验证

Chromium 桌面 1440px、手机宽度 320/390/430px；完成动画及补位、增删改、过滤、置顶、撤销、刷新保存、外观设置、减少动态效果和空清单状态。未执行 iPhone 真机或 Safari 验证。

PWA 已通过 Chromium 的离线重载、离线完成、待办和外观持久化、手动更新保留数据、旧缓存清理和图标尺寸检查。

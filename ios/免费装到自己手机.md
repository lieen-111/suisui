# 免费装到自己 iPhone（不交 ¥688，不需要 Mac）

用普通的免费 Apple ID 给碎碎清单签名，装到你自己的手机上。装好后是真正的原生 App：锁屏小组件、锁屏实时活动卡片，亮屏后直接点圆圈完成。

## 先知道这些限制（苹果对免费 Apple ID 的规定）

- 签名 **7 天有效**，到期后 App 打不开，需要重新签一次。数据不会丢（同一个 App 覆盖安装）。
- 同一个 Apple ID 最多同时装 **3 个**自签 App；每 7 天最多注册 10 个 App ID（碎碎清单占 2 个：主 App + 小组件）。
- 只能装到你自己连接电脑的手机上。给朋友用，要么他们各自按本文操作，要么走 TestFlight（需 ¥688/年，见 `README.md`）。
- iPhone 需要 iOS 17 或更高版本，并打开“开发者模式”。

## 需要准备

- 一台 Windows 电脑和 iPhone 数据线。
- 一个 Apple ID（建议另外注册一个专门用来签名的，不用主账号）。
- 一个 GitHub 免费账号（用来借云端 Mac 编译）。

## 远程、免费的做法（推荐）：SideStore

手机不在身边时，按网站上的 `iphone.html`（仓库 `app/iphone.html`）把步骤发给拿手机的人：

1. **只需一次**：对方用 Windows/Mac 电脑和数据线，按 sidestore.io 官方说明装好 SideStore（iOS 26 用官网推荐的 iLoader），登录免费 Apple ID。
2. 之后都在手机上：打开 https://github.com/lieen-111/suisui/releases/download/ios-latest/suisui.ipa 下载安装包，在 SideStore「我的 App」点 + 选它安装。**不要装进 LiveContainer**（LiveContainer 里的 App 没有小组件）。
3. 每 7 天在 SideStore 里刷新一次；有新版本重新下载覆盖安装，数据保留。

`ios-sideload-ipa.yml` 每次编译后会把安装包更新到固定的 `ios-latest` 发布，手机能直接下载，不用登录 GitHub。完全不用电脑、又免费的原生安装方式不存在；不要用“免费签名 / 企业证书”网站。

## 用 Sideloadly 的做法（电脑在手机旁边）

## 第 1 步：在云端编出安装包

1. 把整个项目放进你的 GitHub 仓库（建议设为公开，公开仓库的 Mac 编译免费）。
2. 打开仓库的 **Actions** → 左侧选 **iOS sideload IPA** → **Run workflow**。
3. 大约 10 分钟后运行变成绿色，在页面底部 Artifacts 里下载 **SuiSui-sideload**，解压得到 `SuiSui-数字.ipa`。

第一次编译如果是红色，把运行页面里的报错（或 `sideload-build-log`）发给 Claude 修。

## 第 2 步：在 Windows 上签名并安装（用 Sideloadly）

1. 从官网 sideloadly.io 下载安装 Sideloadly。
2. 从苹果官网安装 **iTunes 和 iCloud 的网页下载版**（不要用微软商店版，否则电脑认不出 iPhone）。
3. iPhone 用数据线连电脑，手机上点“信任此电脑”。
4. 打开 Sideloadly：把 `.ipa` 拖进去，填 Apple ID，点 **Start**，按提示输入密码和双重认证验证码。
5. 看到 “Done” 即安装完成。

## 第 3 步：iPhone 上放行

1. 设置 → 隐私与安全性 → **开发者模式** → 打开，按提示重启，再确认开启。
2. 设置 → 通用 → **VPN 与设备管理** → 点你的 Apple ID → **信任**。
3. 打开碎碎清单。

## 第 4 步：放到锁屏

- **锁屏小组件（一直显示）：** 锁屏状态长按屏幕 → 自定 → 锁定屏幕 → 点时间下方的小组件区 → 找到“碎碎清单” → 选长条那一款。亮屏后面容 ID 解锁（锁头打开），直接点圆圈完成。
- **锁屏大卡片（实时活动）：** App 里“锁屏”页点“在锁屏显示”。每次最长 8 小时；打开 App 会自动重新显示，也可以按“锁屏”页说明设置快捷指令每天早上自动出现。

## 每 7 天续签

- 最简单：再用 Sideloadly 拖同一个 `.ipa` 装一次（可以勾选 Sideloadly 的自动刷新，电脑开着、同一个 Wi-Fi 时自动续签）。
- 不想每周连电脑：可以改用 SideStore，第一次用电脑设置好后，以后在手机上就能续签（设置步骤比 Sideloadly 多）。

## 常见问题

- **装好了但锁屏小组件里看不到数据：** 说明签名工具没有保留“App Group”共享权限。先在 Sideloadly 的高级选项里确认没有勾选去掉扩展；仍不行就把情况告诉 Claude。App 已内置自动识别改名后的共享组，大多数情况下不用处理。
- **提示达到 App ID 上限：** 等 7 天，或换一个 Apple ID。
- **7 天后打不开：** 正常现象，重新签一次即可，待办还在。

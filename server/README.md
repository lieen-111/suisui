# 碎碎清单 Pro 管理后台

安卓版和网页版的 Pro 靠这个后台开通。它负责四件事：

1. **收款开通**：两种付款方式任选其一。
   - 扫码付款：用你自己的收款码，你在后台确认收款。
   - 爱发电：系统自动核对。
2. **兑换码**：生成、导出、停用，查看每个码绑定了哪些设备。
3. **统计**：收入（今天 / 7 天 / 30 天 / 累计）、每天收入图、订单、已开通的设备、兑换码使用率。
4. **售后**：退款后撤销开通；买家换手机时，清空兑换码绑定的设备。

iPhone 版走 App Store 内购，不经过这里（苹果不允许 App 内引导到其他付款方式）。

---

## 它是怎么工作的

```
买家手机 ──(下单 / 兑换 / 查询)──▶ 后台 /api ──▶ SQLite 数据库（一个文件）
                                    ▲
你（浏览器 /admin）───────────────────┘   确认收款、生成兑换码、看统计
```

- 后台为每台开通的设备签一张**开通凭证**（ECDSA P-256 数字签名）。
- App 里内置了**公钥**，每次启动都会自己验证凭证。所以开通以后不联网也能用，后台临时宕机也不影响已开通的人。
- 只有付款、兑换和每隔几天的状态确认（处理退款）才会连后台。
- 一个兑换码可以在几台设备上用，数量在后台设置，默认 3 台。
- 买家付款后，App 会显示他自己的兑换码，换手机时就用这个码。

### 两种付款方式怎么选

| | 扫码付款（你的收款码） | 爱发电 |
|---|---|---|
| 开通速度 | 你看到到账、点「确认收款」后自动开通 | 买家填订单号，立即开通 |
| 你要做的 | 每单在后台点一下 | 不用管 |
| 手续费 | 无 | 爱发电平台收取（以爱发电规则为准） |
| 买家体验 | 存二维码 → 微信 / 支付宝扫 → 备注订单号 | 跳到爱发电付款 → 回来粘贴订单号 |
| 需要 | 上传收款码图片 | 爱发电账号的 user_id、API Token 和商品链接 |

两种方式都能同时用兑换码，比如在小红书、闲鱼卖码，或者送人。

> 用个人收款码收经营性款项，平台可能会限额或风控。量大以后，建议换成爱发电，或用个体户 / 公司主体开通正式的商户收款。

## 一、先在自己电脑上试一试（5 分钟）

需要 **Node.js 22.13 或更新版本**（自带 SQLite，不用装任何依赖）。

```bash
cd suisui
npm run server
```

Windows 可以直接双击 `server/START-SERVER-WINDOWS.cmd`。

第一次启动，窗口里会打印一行：

```
第一次使用：打开 http://localhost:8787/admin/ ，设置口令是  xxxxxxxx  （用一次就失效）
```

打开这个地址，填入设置口令，再设一个至少 10 位的管理密码，就进入后台了。

数据都在 `server/data/` 文件夹里：

- `suisui.db`：数据库。
- `license-key.pem`：签名私钥。
- `backups/`：自动备份。

这样只能在本机访问，手机连不上。正式使用请看第二步。

## 二、正式上线：放到一台云服务器上

手机上的 App 只能通过 **HTTPS** 连后台，所以需要三样东西：一台服务器、一个域名、一张 HTTPS 证书（证书可以自动申请）。

### 1. 准备服务器和域名

- **服务器**：选一台最便宜的轻量云服务器即可（1 核 1G 就够，这个后台几乎不占资源）。
  - 选**香港、新加坡等境外地域**，域名不需要备案，当天就能用。
  - 选中国大陆地域访问更快，但域名必须先做 **ICP 备案**（一般要 1 到 3 周）。
  - 系统选 **Ubuntu 22.04 / 24.04**。
- **域名**：在腾讯云、阿里云等平台买一个，添加一条 A 记录，比如 `pay.你的域名.com`，指向服务器的公网 IP。
- **防火墙 / 安全组**：只放行 22（SSH）、80、443 三个端口。8787 不要对外开放。

### 2. 安装（一条命令）

用云服务器控制台的「远程登录 / 终端」登录服务器，粘贴下面这一行（把 `pay.你的域名.com` 换成你的域名）：

```bash
curl -fsSL https://raw.githubusercontent.com/lieen-111/suisui/premium/server/deploy/install.sh | sudo bash -s -- pay.你的域名.com
```

脚本会装好 Node.js 22 和 Caddy，下载代码，设成开机自启，并自动申请 HTTPS 证书，大约 3 分钟。最后屏幕上会打印：

- 网页版：`https://pay.你的域名.com/`，碎碎清单网页版，可以替代 Netlify。
- 管理后台：`https://pay.你的域名.com/admin/`
- 设置口令：第一次打开后台时填。

还没买域名的话，可以不写域名：

```bash
curl -fsSL https://raw.githubusercontent.com/lieen-111/suisui/premium/server/deploy/install.sh | sudo bash
```

脚本会用服务器 IP 生成一个 `suisui-1-2-3-4.sslip.io` 的地址，同样带 HTTPS，适合先试用。以后买了域名，带上域名再执行一次就能换过去。不过 App 里写死的是后台地址，所以**正式打包前要先定好域名**。

以后更新代码也是再执行一次这条命令，数据不受影响。

打不开时检查两件事：

1. 云服务器控制台的「防火墙 / 安全组」有没有放行 80 和 443 端口。
2. 域名的 A 记录有没有指向这台服务器的 IP。

不用脚本、想手动安装的话，按 `deploy/install.sh` 里的步骤执行即可。

也可以用 Docker 部署：

```bash
docker build -t suisui-pro /opt/suisui/server
docker run -d --name suisui-pro -p 127.0.0.1:8787:8787 -v suisui-data:/data --restart unless-stopped suisui-pro
docker logs suisui-pro    # 设置口令
```

前面同样需要配 Caddy 提供 HTTPS。

### 3. 在后台里设置

在后台「设置」页：

1. **价格**：售价、划线价、每个码可用几台设备。
2. **付款方式**，二选一：
   - 扫码付款：上传你的微信或支付宝收款码图片。
   - 爱发电：填写下面这些：
     - **商品链接**。
     - **user_id** 和 **API Token**，在爱发电「开发者」页面找到。
     - 把同一页面的 **Webhook 地址**设成后台显示的那个地址。
     - 点「测试连接」，确认能连上。
3. **联系方式**：显示在 App 付款页底部，买家遇到问题时找你。
4. **后台的公网地址**：填 `https://pay.你的域名.com`。

### 4. 接到 App 上（只做一次）

1. 在后台「设置 → 接到 App 上」点「复制」。
2. 用复制的内容**整个替换** `app/pro-config.js`。里面包括 `freeForTesters: false`、服务器地址和公钥。
3. 推送代码，GitHub Actions 会打出正式版安装包。网页版就是把 `app/` 上传到 Netlify。

> 注意：`freeForTesters: false` 之后，Pro 就要付费才能用了，测试包不要用这份设置。

## 三、日常运营

- **扫码订单**：后台「订单」左侧会显示待确认的数量。
  1. 在微信或支付宝的收款记录里，找到备注里写着订单号的那一笔。
  2. 金额对得上，就点「确认收款」，买家手机几秒内自动开通。
  3. 没收到钱就点「驳回」。
- **退款**：先在微信、支付宝或爱发电里把钱退回去，再在后台把订单点成「退款」。这个订单的兑换码会停用，已开通的设备下次联网时退回免费版。
- **买家换手机、设备满了**：在「兑换码」里找到他的码，点「清空设备」。
- **发码做活动**：在「兑换码 → 生成」里填好批次名，生成后可以「全部复制」或「导出 CSV」。
- **看数据**：「概览」里有今天、近 7 天、近 30 天、累计收入，每天收入图，收入来源，兑换码使用率和最近动态。

## 四、备份（重要）

- 服务器每天自动备份一次数据库到 `data/backups/`，保留 14 天。后台「设置 → 备份」也能随时下载一份完整的数据库。
- **`license-key.pem` 一定要另外备份**，放在你自己的电脑或网盘里。
  - 丢了它，已经开通的用户不受影响，因为 App 只需要公钥。
  - 但之后就签不出新的开通凭证了，只能换一把新钥匙、重新打包 App。
- 迁移到新服务器：把整个数据目录（`suisui.db`、`license-key.pem`、`pay-qr`）拷过去即可。

## 五、更新后台

```bash
cd /opt/suisui && sudo git pull && sudo systemctl restart suisui-pro
```

数据在 `/opt/suisui-data`，更新代码不会影响数据。

## 六、安全

- 管理密码至少 10 位。登录连续失败会被锁 15 分钟。修改密码后，其他地方的登录会全部退出。
- 后台页面禁止被嵌入其他网站，所有修改操作都需要登录，并带防伪请求头。
- 兑换码有 32^12 种组合。猜码会被限流，只计算失败次数，正常买家不会被误伤。
- 爱发电的 Webhook 没有签名，所以后台从不直接相信它，每一单都会用你的 Token 向爱发电 API 再核对一次。
- 不要把 `data/` 提交到 Git（已经写在 `.gitignore` 里）。

## 七、接口一览（给 App 用）

| 接口 | 用途 |
|---|---|
| `GET /api/config` | 价格、付款方式、联系方式 |
| `GET /api/qr` | 收款码图片 |
| `POST /api/orders` | 扫码付款：生成订单号（同一设备只保留一个待付款订单） |
| `POST /api/orders/:id/status` | 查询订单；已确认时返回开通凭证和兑换码 |
| `POST /api/afdian/claim` | 用爱发电订单号开通 |
| `POST /api/afdian/webhook` | 爱发电通知（会向爱发电核对后才记账） |
| `POST /api/redeem` | 兑换码开通（同一设备重复兑换 = 恢复） |
| `POST /api/check` | App 每隔几天确认一次开通是否仍然有效 |

自动测试：`npm run test:server`（后台全流程）和 `npm run test:pay`（App 付款和后台联动，需要先运行 `npm start`）。
